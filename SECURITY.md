# Security Policy

## Intended use

Security Arena is for reviewing software you own or are explicitly authorized to test. Do not use it against third-party or production systems.

## Reporting a problem with this project

If you find a flaw in the skill itself (for example, a way its rules can be bypassed, or an instruction that could lead an agent to unsafe actions), please open an issue. If the problem is sensitive, contact the maintainer privately before publishing details. (Maintainer contact: to be added before the first public release.)

## Scope of guarantees

The skill is a set of instructions. It does not enforce a sandbox. See the Limitations section of the README.
