# TinyBoard (fictional test fixture)

A tiny notice-board web app used to test Security Arena. It is fictional, uses only made-up data, has no dependencies (Node.js built-ins only), and binds to loopback. It is intentionally flawed: never deploy it.

Run locally (only if you have approved it): `node server.js`

Files: `server.js`, `uploads/` (sample files).
